# Requirements

## 機能要件

### カテゴリ管理

| # | 要件 |
|---|------|
| F-25 | ブックマーク登録・編集時にカテゴリを1つ選択できる（未分類も可） |
| F-26 | カテゴリはユーザー単位で管理される（他ユーザーのカテゴリは参照・操作できない） |
| F-27 | 一覧画面でブックマークがカテゴリごとにグルーピング表示される |
| F-28 | カテゴリ未設定のブックマークは「未分類」グループに表示される |
| F-31 | カテゴリ管理モーダルでカテゴリの作成・削除・一覧表示ができる |

### 認証

| # | 要件 |
|---|------|
| F-01 | Clerk を使用してログイン・ログアウトができる |
| F-02 | 未ログインユーザーはブックマーク画面にアクセスできない（ログインページにリダイレクト） |
| F-03 | ログイン後、初回アクセス時に DB へユーザー情報を同期する |

### ブックマーク管理

| # | 要件 |
|---|------|
| F-10 | ログインユーザーは自分のブックマーク一覧を閲覧できる |
| F-11 | ブックマークを新規登録できる（URL・タイトル・メモ・カテゴリ） |
| F-12 | ブックマークを編集できる（URL・タイトル・メモ・カテゴリ） |
| F-13 | ブックマークを削除できる |
| F-14 | 他ユーザーのブックマークは参照・操作できない |

### 検索・表示改善

| # | 要件 |
|---|------|
| F-15 | キーワード検索ができる（title / url / memo に対する部分一致） |
| F-16 | URL 入力時に OGP を自動取得し、タイトル・OGP 画像 URL を補完できる |
| F-20 | ブックマーク削除はソフトデリート（ゴミ箱へ移動）とし、ゴミ箱から復元・完全削除できる |
| F-24 | ドラッグ＆ドロップでブックマーク・カテゴリの並び順を変更できる（並び順は DB に保存） |

### 外部連携

| # | 要件 |
|---|------|
| F-32 | API キー認証で自分のブックマークを JSON 取得できる REST API（`GET /api/bookmarks`）を提供する |
| F-33 | ユーザーは API キーを生成・再生成できる（1 ユーザー 1 キー） |

## 非機能要件

| # | 要件 |
|---|------|
| NF-01 | TypeScript strict モードで実装する |
| NF-02 | Biome でコードフォーマット・リントを統一する |
| NF-03 | API ルート・Server Actions にはユニットテストを作成する |
| NF-04 | 開発環境は devcontainer で統一する |
| NF-05 | 本番 DB は PostgreSQL を使用する |
